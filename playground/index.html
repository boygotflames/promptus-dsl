CLI flow

Keep the developer loop short: validate first, transpile next, run only when the payload is explicit.

llm_format validate sentiment.llm
llm_format transpile sentiment.llm --target openai-chat
llm_format run sentiment.llm --provider openai --model gpt-4o-mini

Core features

The value is not speculative syntax. It is a compiler-backed workflow for structured prompt authoring, validation, transpilation, and execution.

01

Validate before runtime

Catch missing required keys, type mismatches, undefined vars, include cycles, and merge conflicts before any API call is made.

02

Compile to OpenAI Chat JSON

Emit a clean Chat Completions payload ready for CLI previews, direct HTTP calls, or SDK handoff.

03

Compile to Anthropic Messages JSON

Generate the Messages API shape directly, with the compiler handling prompt normalization before the request is sent.

04

Format and lint .llm files

Use canonical formatting for stable diffs and lint rules for prompt quality issues that are worth catching before execution.

05

Compose prompts with include and vars

Share base instructions across files, merge structured prompt sections, and expand vars at compile time.

06

Execute live requests with run

Validate, transpile, inject model settings, and send provider-native requests from the CLI with a single command.
