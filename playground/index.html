Compiler Pipeline

Promptus DSL replaces plastic markdown prompt blobs with a structured, compiler-checked pipeline.

01

Authoring Layer

Write prompt structure using an indentation-based DSL that captures logical components: agent metadata, instruction blocks, vars, and validation schemas.

agent: SentimentAnalyzer
system:
  role: classifier
02

Static Validation

Catch structural compile-time errors like missing required fields, undefined variable references, and circular include chains before sending API calls.

[E101] missing required key: system
[E114] undefined var reference: {input_text}
03

Formatting & Linting

Enforce canonical quoting, indentation rails, and file styles. Apply static quality rules like warning on empty schemas or overly long system prompts.

[L001] missing output schema
[L003] system prompt very short (< 20 chars)
04

Composition & Variables

Share common files across your workspace using the composition directive include, and expand templates dynamically at compile time.

include: shared/base-system.llm
vars:
  input_text: "Day one break."
05

Provider Target Generation

Generate clean, provider-native JSON payloads mapped to the structural formats expected by OpenAI Chat Completions or Anthropic Messages.

# Mapped system prompt content insideMessages API:
"system": "role: classifier\ninstruction: Classify..."
06

Deterministic Execution

Run prompt validation, compile payloads, load models, and run requests against live provider APIs directly from a single CLI execution.

$ llm_format run sentiment.llm --provider openai
